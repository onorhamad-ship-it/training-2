# Aldi Supermarket Sales Analysis

A Python script designed to process supermarket sales records, calculate total store revenue, track total units sold, and identify top-performing products.

---

## 📌 Features
* **Sales Summary Report:** Generates a formatted breakdown of items sold by category, unit count, and individual product revenue.
* **Key Metrics Tracked:**
  * Total store revenue
  * Total unique items tracked
  * Total units sold across all categories
  * Identification of the top-performing item by revenue

---

## 🛠️ Requirements
* Python 3.x installed on your local machine.

---

## 🚀 How to Run locally

1. Clone or download this repository to your local computer.
2. Open your terminal or PowerShell window inside the project directory.
3. Run the Python script:

```bash
python sales_summary.py
